📘 Guides 実装手順

プロジェクト全体の進め方・Phase 単位の手順を示すドキュメント。「これから何をするか」を最初に読む。

  • Phase 2 ガイド：しきい値判定・Discord通知・定期実行 2026-10-09 Phase 2

    Phase 1完了を受けて作成。F（しきい値判定ロジック NotificationDecision）→G（通知ポート抽象化＋Discord通知）→H（@Scheduledで定期実行化）→I（動作確認）の順で進める理由と穴埋め骨格。「自動化は最後」の設計判断を解説。

  • Phase 1 完成：ingest を動かして DB保存を確認する 2026-06-14 Phase 1

    コンパイルが通った ingest() を実際に起動して DB に保存するまで。実行で落ちる3課題（createdAt自動設定@PrePersist・@Transactional・重複防止existsBy）＋ CommandLineRunner による起動トリガー＋動作確認手順。各課題に穴埋め骨格と理解度チェック付き。これでPhase 1クリア。

  • レイヤー構成とパッケージの役割（client / dto / service / entity / repository） 2026-06-14 Phase 1

    5つのパッケージが「何をする係か」を、自分が書いた実コード（PollenApiClient / PollenCsvRow / PollenIngestService / PollenMeasurement / *Repository）を題材に解説。データの流れのSVG図、責務対比表、やりがちな混同、Phase 4(DDD)への伏線、理解度チェック付き。初学者向け。

  • 外部API連携ガイド（RestClient + CSV + DTO → Entity） 2026-06-03 Phase 1

    Phase 1の本丸。ポールンロボAPI(CSV)取得→DTO→PollenMeasurement.of()→save の4層フロー。RestClient・Commons CSVパース・-9999欠測の判断・地点解決・重複防止・@Transactional。各ステップに穴埋め骨格と課題。

  • Repository 実装ガイド（Spring Data JPA） 2026-05-31 Phase 1

    Entity の次のステップ。JpaRepository の継承、タダで手に入るメソッド、派生クエリ命名規約、external_id検索・重複防止メソッドの書き方（あなたが書く課題付き）。

  • IntelliJ IDEA & Gradle 使い方ガイド 2026-05-31 Phase 1

    gradlew コマンドをどこで打つか（内蔵ターミナル/Gradleパネル/OSターミナル）、IntelliJ Community 2025.2 の画面構成・操作・ビルドエラーの読み方・ショートカット。

  • Phase 1 ユーザー実装ガイド 2026-05-25 Phase 1

    Entity → Repository → DTO → Client → Service → Controller の実装順序、レイヤー依存図、Step 1〜6 の詳細。

📗 References リファレンス

特定の技術・ライブラリの使い方・罠をまとめた参照資料。書いている途中で何度も戻ってくる。

  • ポールンロボAPI 仕様メモ（観察結果＋用語対応） 2026-06-03 Phase 1

    実レスポンス観察記録。CSV列(citycode/date/pollen)とユビキタス言語・Entity/DTOの対応表、date形式(+09:00→Instant)、0と欠測(負数)の違い、3月/6月の実例、変換フロー、未確認論点。

  • 派生クエリ：メソッド名がそのままSQLになる仕組み 2026-06-03 Phase 1

    「findBy用の既製関数」は存在せず、メソッド名という文字列を解析してクエリを生成する——という核心。主部/述部の解剖、主部・述部キーワード一覧、本プロジェクト2例の完全分解、戻り値とDB制約の整合、プロパティ掘り下げ、@Queryへの切り替え。

  • Spring Data JPA はどこで実装されるのか（内部の仕組み） 2026-06-01 Phase 1

    findByXxx の実装が「どこにも無い」理由。起動時のプロキシ生成フロー、SimpleJpaRepositoryへの委譲、PartTreeによるメソッド名解析、トランザクション、起動時fail-fast、show-sqlでの確認方法。

  • 命名規則リファレンス（Java / JPA / DB） 2026-05-31 Phase 1

    PascalCase / camelCase / snake_case / UPPER_SNAKE の使い分け、Java↔DBの命名自動変換、テーブル・列・FK・シーケンスの命名、ファクトリ命名（of/from/valueOf）、やりがちな失敗。

  • JPA アノテーション リファレンス 2026-05-27 Phase 1

    @Entity, @Id, @GeneratedValue, @SequenceGenerator, @Column, @ManyToOne, @JoinColumn 等の用途・使用例・メリット/デメリット・本プロジェクト推奨。最小構成テンプレ付き。
